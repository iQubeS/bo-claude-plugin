# Hvordan bruke en QCP

![bilde](gitbook-file:OJXfnB6aJ8HynE4hOxcN)

Inne i et arbeidsrom med en tilknyttet prosess oppfordres brukeren til å følge prosessen.

En QCP er et prosessverktøy for bedriften for å sikre kvalitet i den daglige driften. Men også et verktøy for brukeren for å gi de riktige dokumentene til rett tid, automatisk oppdatere prosjektfremdriften eller gå over til neste fase i prosessen.

> ℹ️ **INFO**
> Du kan finne mer informasjon om hvordan du oppretter og administrerer en prosess [her]().

# Inne i et arbeidsrom

Når du går inn i et arbeidsrom med en prosess vil du se webdelen for kvalitetskontrollplan øverst på siden.

Fargen på fasens sirkel indikerer hvilken status fasen har. En fases sirkel kan være delvis farget dersom de tilhørende sjekkpunktene har forskjellige statuser. Fargene og statusene er:

Blå = Startet
Grønn = Fullført
Mørkgrå = Ikke anvendelig
Rød = Avvik til sjekkpunkt (prosessen)

Når du klikker på en fase blir du omdirigert til fasesjekklistegrensesnittet. Her vil brukeren dokumentere at det jobbes i henhold til prosessen for gjeldende arbeidsrom.

| # | Beskrivelse |
| --- | --- |
|  | Fasetittel med fremdrift basert på utførte oppgaver |
|  | Verktøytips for kontrollpunktstatus. Her kan du se hvem som gjorde hva når. Når en status endres, registreres dataene med data og hvem som gjorde statusendringen. |
|  | Tittelen på sjekkpunktet |
|  | Beskrivelse av sjekkpunktet |
|  | Statusvalg, her kan du endre statusen til sjekkpunktet. Fullført vil oppdatere %-fremdriften til fasen. Status kan inneholde [utløsere](), [avhengighet]() eller [fremhev innhold](). |
|  | [Arbeidsfiler]() forsyner brukeren med relevante dokumenter for sjekkpunktet. Dette vil kopiere en versjon fra de styrende dokumentene som brukeren kan jobbe med i arbeidsområdet. |
|  | [Linker ]()er der brukeren kan finne relevante lenker om sjekkpunktet. Linker kan også inneholde [triggerskjemaer](). |
|  | Legg til en kommentar til sjekkpunktet. Typisk det som er gjort. |
