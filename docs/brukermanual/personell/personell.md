# Introduksjon

Personellistens primære bruk er å lagre bedriftsrelevant informasjon og dokumentasjon om nåværende og tidligere ansatte / ressurser.

![bilde](gitbook-file:0blD4j6cZkD0KJlkzhX9)

## Tilgjengelighet

Denne listen er sterkt tilgangskontrollert på grunn av potensiell sensitiv data som lagres, som kan sees i [tilgangsmatrisen](), med bare HR-gruppen som kan bidra. Ved opprettelse av et personell element kan imidlertid bare én enkelt person utnevnes som den ansattes rapporteringsansvarlige, som kan bidra i den ansattes arbeidsrom.

# Opprette et nytt personell element

Et nytt personell element kan opprettes ved å klikke på +Ny-knappen som vil omdirigere brukeren til et nytt element skjema. Bruk skjemaet for å legge til ansattes relevante data og lagre for å opprette elementet.

> ℹ️ **INFO**
> En gyldig Business Online-bruker og brukernavn kreves for at den ansatte skal kunne opprettes.

### Feltbeskrivelse

Standard ansattskjema viser følgende seksjoner og felt.

> ⚠️ **WARNING**
> Noen felt, merket med rød *, er obligatoriske for at elementet skal kunne opprettes.

**Ansattoversikt**

| Felt | Beskrivelse |
| --- | --- |
| Fornavn | Ansatts fornavn |
| Etternavn * | Ansatts etternavn |
| Avdeling | Arbeidsavdeling |
| Ansatt nummer | Ansattes arbeids-ID |
| Brukernavn * | En gyldig Business Online-bruker og brukernavn |
| Kjønn | Ansattes kjønn |
| Fødselsdato | Ansattes fødselsdato |
| Personelltype * | Nedtrekksmeny for å definere type personell |

**Kontaktinformasjon**

Disse feltene kan den ansatte legge til selv og endre på fra *Min Side. *

| Felt | Beskrivelse |
| --- | --- |
| E-post | Personlig epost |
| Mobil | Personlig eller jobbmobilnummer |
| Addresse | Bostedsadresse |

**Jobbinformasjon**

| Felt | Beskrivelse |
| --- | --- |
| Tittel / stilling | Jobb tittel eller stillingsbeskrivelse |
| Ansettelsesdato | Dato for ansettelse |
| Status | Nåværende ansettelsesstatus |
| Rapporteringsansvarlig | Rapporteringsansvarlig. Krever en gyldig Business Online-bruker og brukernavn. Ansvarlig vil få tilgang til den ansattes arbeidsrom og konfidensiell data |
| Prestasjons evalueringsdato | Dato for når den ansattes prestasjoner vil bli evaluert |

**Pårørende**

| Felt | Beskrivelse |
| --- | --- |
| Primærkontakt forhold | Primærkontakts forhold til den ansatte |
| Primærkontakt navn | Primærkontaktens fulle navn |
| Primærkontakt mobil | Primærkontakts personlige mobilnummer |
| Sekundærkontakt forhold | Sekundærkontakts forhold til den ansatte |
| Sekundærkontakt navn | Sekundærkontaktens fulle navn |
| Sekundærkontakt mobil | SSekundærkontakts personlige mobilnummer |

> ✅ **SUCCESS**
> Etter noen sekunder vil det vises en link til elementets [arbeidsrom](), som er der den ansattes konfidensielle data vil bli lagret.

# Redigere et eksisterende personell element

Et personell element kan oppdateres eller redigeres ved å bruke elementets redigeringsskjema. For å komme til redigeringsskjema klikker du på pen-ikonet ved siden av den ansattes navn. Redigeringsskjema er likt skjema for opprettelse av nytt element. 

Når endringene er utført klikker du **Lagre **knappen øverst eller nederst i skjemaet.

![bilde](gitbook-file:ETIYfmKugDcTtHhFp7QP)

## Hvorfor redigere?

Hensikten med å redigere et personell element kan f.eks. være å oppdatere den ansattes ansettelsesstatus i selskapet. Hvis du endrer statusen til et personell element til sluttet vil elementet automatisk skjules fra alle aktive visninger og settes til inaktiv/arkivert.

# Vise data for et eksisterende personell element

Klikk på den ansattes etternavn for å vise personopplysningene hans/hennes. Merk at dataene ikke kan redigeres gjennom dette skjemaet.

![bilde](gitbook-file:NkME7hrEo7XFVpH4p56y)

# Slette et personell element

> 🚨 **DANGER**
> Slett element funksjonaliteten skal bare brukes hvis elementet ikke har noen arkivert verdi. F.eks. elementet er et duplikat, elementet er opprettet ved en feil, elementet brukes som testelement, etc.


Elementer kan, og bør, arkiveres ved å [redigere]() statusen.

Et personell element kan slettes ved å trykke på de tre prikkene og velge **Slett** på menyen eller ved å markere elementet og trykke på **Delete**-knappen på tastaturet. Et popup-vindu som ber om bekreftelse av sletting vil vises.

![bilde](gitbook-file:PosAUCifbPClHRjKKUUG)

> ℹ️ **INFO**
> Slettede elementer kan gjenopprettes fra papirkurven.
