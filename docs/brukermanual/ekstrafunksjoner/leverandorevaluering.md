# Introduksjon

Integrert i CRM-modulen, gir leverandørevaluering mulighet for periodiske og regelmessige vurderinger av dine leverandører. Resultatet er en overordnet poengsum. Denne funksjonen er et perfekt supplement til aktsomhetsvurderinger dersom din bedrift er underlagt Åpenhetsloven.

Tilleggsfunksjonen vil være tilgjengelig på arbeidsrommet til bedrifter som er av typen *leverandør,* i menyen på venstre side. 

## Oversikt over leverandører

Fra CRM-modulen klikker du deg inn på listen for Bedrifter. Her kan du enkelt filtrere frem leverandører ved å bruke listevisningen for *Aktive Leverandører. *Du får da en oversikt over alle aktive leverandører og siste leverandørevaluerings poengsum.  

Denne listevisnignen kan justeres på etter behov.

![bilde](gitbook-file:mwY6oB8vKqUI176J26VJ)

| Felt | Beskrivelse |
| --- | --- |
| UID | Unikt ID nummer |
| Bedriftsnavn | Bedriftsnavn |
| Link | Link til arbeidsrommer for bedriften |
| Aktiv | Sjekk-symbol for om leverandøren er aktiv |
| Godkjent leverandør | Ja/Nei |
| Intern ansvarlig | Navnet på ansatt i egen bedrift som er ansvarlig for leverandøren |
| Nettside | Leverandørens nettside |
| Leverandør score | Grønt, gult eller rødt felt med poengsum som indikerer hvordan leverandøren leverer fra 1-5. |

## Opprette en ny leverandørevaluering

I denne tilleggsfunksjonen kan du gjøre flere evaluering i samsvar med din bedrifts ønske eller prosedyre. 

For å gjøre en leverandørevaluering må du klikke deg inn på leverandørens arbeidsrom. 

| Felt | Beskrivelse |
| --- | --- |
| Evaluering tittel | Tittel for evaluering. Eks: Måned/kvartal/år |
| Selskapsnavn | Velg hvilken bedrift evalueringen gjelder |
| Leverandørkategori | Velg leverandør kategori. Velg mellom A-Kritisk, B-Kritisk, eller C-Annet |
| Godkjent leverandør | Velg om leverandøren er godkjent, ikke godkjent eller under vurdering |
| Leverandørevaluering | Felt med mulighet for å skrive en evaluering av leverandøren som kommentar |
| Webside | Nettsiden til bedriften |
| Beskrivelse | Låst felt. Beskrivelse av nettadressen. Kan redigeres fra bedriftens redigerinsskjema |
| Leverandørspørreskjema motatt | Låst felt. Fra bedriftens redigerinsskjema er det huket av for om din bedrift har mottatt spørreskjema ved inngåelse av kontrakt. Dette vil være definert i bedriftens egen prosedyre |
| ISO | Låst felt. Fra bedriftens redigerinsskjema er det huket av for de aktuelle ISO sertifiseringene leverandøren har. |
| Dekkes av åpenhetsloven | Låst felt. Fra bedriftens redigerinsskjema er det huket om leverandøren er dekket av åpenhetsloven |
| **Evaluering** | Syv kriterier som skal svares på med avkryssing. Hver svar gir følgende poeng til total poengsum: Svært dårlig - 1  Dårlig - 2 Greit - 3 Bra - 4Svært bra - 5Definisjon for de ulike nivåene må defineres i bedriftens egen prosedyre. |
| Sum | Total poengsum basert på svar på kriterier |
| Neste evaluering | Velg dato for neste evaluering |
| Kommentar | Legg til en kommentar som beskriver evaluering svarene |

## Visning av leverandørevalueringer

Når en leverandørevaluering er gjennomført vil den ligge i en låst listevisning med informasjon om tittel, dato for gjennomfæring, poegsum/score og dato for neste evaluering. 

![bilde](gitbook-file:g0XwXk3oaGBFcIF0Kwal)

Ved å trykke på øye-symbolet får du opp en visning for evalueringen. Det er ikke mulig å redigere på en gjennomført evaluering.
